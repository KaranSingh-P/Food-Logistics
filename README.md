## User Settings

The User setting is stored in permanently using the PostgreSQL tables - users, user_allergies, user_settings

Username -> user_setting
Email(Fixed) <- users
Password -> users
Theme -> user_setting
Allergies -> user_allergies (as allergy_id of allergies table)
